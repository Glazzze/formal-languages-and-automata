## 运行环境与方法

使用 Python 3.9 或以上版本，仅依赖标准库。三题入口均使用内置用例，无需命令行参数或交互输入。进入解压后包含源码的目录，依次执行以下命令。

```bash
python3 question1_dfa_equivalence.py
python3 question2_dfa_minimization.py
python3 question3_stack_membership.py
```

如果系统使用 `python` 命令，将上述命令中的 `python3` 替换为 `python`。

第一、二题共用 `dfa.py` 中的 `Automaton` 类。`dfa_examples.py` 保存题图数据和自构 DFA，`dfa_display.py` 打印第二题的合并过程和完整结果。三题的自构语言、转移表和预期结果见 [自构用例.txt](自构用例.txt)。

## 各题输入与预期结果

### 第一题 · DFA 语言等价判定

运行 `question1_dfa_equivalence.py`，主要函数为 `are_equivalent(a1, a2)`。函数搜索乘积自动机中可达的状态对，寻找两台 DFA 接受性不同的状态对。

| 输入 | 预期结果 |
| --- | --- |
| 题图中的两台 DFA | 不等价，最短区分串为 `ε` |
| 自构的 2 状态 DFA P1 和 3 状态 DFA P2 | 等价，均接受以 `0` 结尾的二进制串 |

### 第二题 · DFA 最小化

运行 `question2_dfa_minimization.py`，主要函数为 `minimize_dfa(dfa)`，返回最小化 DFA 与可达原状态到新状态的映射。程序输出状态、字母表、初态、终态、完整转移表和合并关系。

题图 DFA D 由 7 个状态缩减为 3 个。初态是 `Q1`，唯一终态是 `Q0`。

| 新状态 | 原状态 | 输入 `0` | 输入 `1` |
| --- | --- | --- | --- |
| `Q0` | `FS2, FS5, FS6` | `Q1` | `Q1` |
| `Q1` | `IS0, S3` | `Q2` | `Q2` |
| `Q2` | `S1, S4` | `Q0` | `Q0` |

自构用例 A 将等价状态 `B`、`C` 合并并删除不可达状态 `X`。自构用例 B 识别含偶数个 `1` 的二进制串，最小化后仍有 2 个状态。

### 第三题 · 堆栈判定

运行 `question3_stack_membership.py`，主要函数为 `judge(s)`，使用显式堆栈判定输入是否属于 `{0^k 1^k | k ≥ 1}`。

| 输入 | 预期输出 |
| --- | --- |
| `01`、`0011`、`000111` | 接受 |
| 空串、`011`、`0101` | 拒绝 |
