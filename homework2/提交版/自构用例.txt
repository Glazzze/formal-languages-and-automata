自构语言与测试用例

运行环境为 Python 3.9 或以上版本，仅使用标准库。在解压后的目录中运行各题。
第一、二题自构 DFA 的可运行定义位于 dfa_examples.py。

一、第一题 · 语言等价判定

自构语言 L = {w ∈ {0,1}* | w 以 0 结尾}。
使用字母表 {0,1} 构造两台不同结构的 DFA。

P1 初态 A，终态集合 {B}
状态    输入 0    输入 1
A       B         A
B       B         A

P2 初态 X，终态集合 {Z}
状态    输入 0    输入 1
X       Z         Y
Y       Z         X
Z       Z         X

P2 中 X、Y 都是非终态，读 0 均进入 Z，读 1 均留在非终态组中。
合并 X、Y 后得到与 P1 同构的自动机。两台 DFA 都接受 0、10、110，
都拒绝空串、1、101。
运行 python3 question1_dfa_equivalence.py，自构正例预期输出“等价”。

二、第二题 · DFA 最小化

用例 A 同时检查状态合并与不可达状态删除。
字母表 {0,1}，初态 A，终态集合 {B,C}。
状态    输入 0    输入 1
A       B         C
B       B         B
C       C         C
X       X         X

预期删除不可达状态 X，将 B、C 合并。最小 DFA 的初态为 Q0={A}，
终态为 Q1={B,C}，Q0 读 0 或 1 均转到 Q1，Q1 在两个符号上均自循环。
两台 DFA 接受所有非空二进制串。

用例 B 检查已最小的 DFA。
字母表 {0,1}，初态 E，终态集合 {E}。
状态    输入 0    输入 1
E       E         O
O       O         E

预期保留两个状态，映射 E→Q0、O→Q1。两台 DFA 都接受 1 的个数为偶数
的二进制串，包括空串。
运行 python3 question2_dfa_minimization.py，可查看两组自构输入及结果。

三、第三题 · 堆栈判定

题设语言 L = {0^k 1^k | k ≥ 1}。以下用例补充覆盖最短串、长度不等、
顺序错误、非法字符和空串。ε 表示空串。

输入             预期
01               接受
0011             接受（题面示例）
000111           接受
ε                拒绝
0、1、00、11     拒绝
011、0101        拒绝（题面示例）
001、00011       拒绝（1 太少）
001111           拒绝（1 太多）
00110、10        拒绝（0 出现在 1 之后）
00a11            拒绝（存在非法字符）
