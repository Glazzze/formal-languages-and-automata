### 任务包 A：公共类、输入数据与基础测试

1. 阅读课件第 19、30–35、39–42 页，与 B、C 共同确定状态集合、字母表、转移函数、初态、终态集合的表示方式，提供一个可运行的小例子。
2. 在 `dfa.py` 中维护唯一的公共类定义，供第一、二题导入；检查状态引用和转移是否有效。
3. 约定不同字母表、缺失转移的处理方式。DFA 算法需要完整转移时，统一补陷阱状态；不能让两题采用互相冲突的输入规则。
4. 录入第一题两个反例自动机和第二题自动机 D 的转移表；由另一位成员对照 PDF 图逐条复核，特别检查双符号边和终态。
5. 编写公共类基础测试：有效构造、无效状态引用、缺失转移的约定处理、单步转移与字符串运行；整理接口说明。公共类交付后复核 D 的第三题变量限制，并协助修复接口问题。

### 任务包 B：第一题等价判定与等价性复核

1. 阅读课件第 19、30–35 页，基于公共类实现通用的 `are_equivalent(a1, a2)`。按乘积 DFA 的思路，从初态对搜索；若到达恰有一个分量为终态的状态对，则不等价；遍历完可达状态对仍未发现，则等价。
2. 使用题图两个自动机作为反例，打印“不等价”；另构造一对与题图不同的等价自动机，打印“等价”。
3. 自构正例建议使用不同状态数量或结构，说明它们为什么接受同一语言，避免仅复制同一个自动机。
4. 检查初态接受性不同、状态同名、不可达状态等情况；不能只通过有限个字符串判断一般语言等价。
5. 提交算法说明、完整输入数据及实际输出；负责调用等价函数复核 C 的最小化结果，与 D 的独立短串验证相互补充。

### 任务包 C：第二题最小化与最小性说明

1. 阅读课件第 39–50 页，基于公共类实现通用的 `minimize_dfa(dfa)`，返回新的自动机对象，供组长调用并输出；另提供原状态到新状态的映射，具体接口在首次确认时固定。
2. 按课件状态对标记法，先标记接受性不同的状态对，再迭代传播标记，最后合并未标记的状态对；按第 50 页处理不可达状态。
3. 用题图 7 状态自动机 D 运行，提供原状态到合并后状态的对应关系，以及新初态、终态和完整转移。
4. 增加至少一个自构 DFA 测试，说明函数能处理题图以外的输入；覆盖“已经最小”和“存在不可达状态”等情况。
5. 提交算法说明和最小性依据：结果所有状态均可达，各不同状态对均可区分。与组长核对输出，由 B 检查语言等价性，由 D 独立抽查合并结果。

### 任务包 D：第三题堆栈判定与独立验证

1. 只使用显式堆栈 S、输入 s 和必要的遍历循环变量实现判定；不引入计数器、阶段标志、结果变量、额外列表或递归。
2. 保证字符串先为连续的 0，再为同样数量的 1，且至少各有一个；需要记录的信息应通过允许使用的堆栈及控制流程表达。
3. 正确处理 `0011`、`011`、`0101` 等题目示例，输出规定的中文结论。
4. 将判定核心与独立测试脚本区分开，受限程序中不混入测试统计变量；与 A 和组长逐行审查题面允许的变量。第三题测试覆盖下表全部用例，并说明如何避免先读入 1 后又读入 0 被误接收。
5. 在独立的 `verify_submission.py` 中，为第一、二题编写补充验证：枚举短串比较两个输入 DFA 的接受结果，以及原 DFA 和最小化结果的接受结果；该脚本不受第三题判定核心的变量限制约束。短串测试仅用于查错，不能替代通用等价算法。
6. 独立核对 A 录入的两张题图数据，按课件状态对方法人工抽查 C 的合并关系，提供预期与实际结果对照。提交第三题算法说明、变量使用说明和跨题测试记录。
