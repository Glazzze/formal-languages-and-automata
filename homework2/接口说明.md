## 2. 公共类 `Automaton`

```python
@dataclass(frozen=True)
class Automaton:
    states: List[str]
    alphabet: List[str]
    start_state: str
    accepting_states: Set[str]
    transitions: Dict[str, Dict[str, str]]
```

`transitions[state][symbol]` 是嵌套字典，表示 δ(state, symbol)。构造时会对
传入的列表、集合和字典做**防御性复制**，之后修改调用方对象不会影响实例。

### 2.1 不变量

1. 状态名、字母表符号都是非空字符串；状态名和字母表符号各自唯一。
2. `start_state` 属于 `states`，`accepting_states` 是 `states` 的子集。
3. `transitions` 是**全函数**：每个状态有一行，每个字母都有转移；转移
   目标属于 `states`，不允许未知状态、未知符号或多余的状态行。
4. 允许存在不可达状态；最小化时由第二题负责删除。
5. 字段类型保持 `List` / `Set`，这是第二题现有单元测试的硬性断言，例如
   `minimized.states == ["Q0", "Q1", "Q2"]`、`minimized.alphabet == ["0", "1"]`。

### 2.2 异常约定

| 情况 | 异常 |
| --- | --- |
| 状态/符号重复、初态或终态未知、缺少转移、转移指向未知状态、转移含字母表外符号 | `ValueError` |
| 状态名、符号、转移目标不是字符串 | `TypeError` |
| `delta` 查询未知状态/符号，`accepts` 遇到字母表外字符 | `ValueError` |
| `accepts` 的参数不是字符串 | `TypeError` |

严格校验的目的是把“录入错误”与“合法但部分”区分开：题图数据录错时必须
立刻报错，而不是靠补陷阱把错误掩盖掉。

### 2.3 方法

| 方法 | 说明 |
| --- | --- |
| `delta(state, symbol) -> str` | δ(state, symbol)，带参数检查 |
| `is_final(state) -> bool` | 是否为终态 |
| `accepts(word) -> bool` | 从初态读完整串，返回是否接受；空串按初态判断 |
| `reachable_states() -> List[str]` | 从初态可达的状态，按名字排序 |
| `pretty_print(label="DFA")` | 打印状态集、字母表、初态、终态、完整转移表 |
| `from_partial(...) -> Automaton` | 由部分转移表构造，统一补陷阱状态 |
| `complete_to(alphabet) -> Automaton` | 把字母表扩到指定集合，新符号进入陷阱 |

模块级函数：

| 函数 | 说明 |
| --- | --- |
| `common_alphabet(*automata) -> List[str]` | 字母表并集，排序后返回 |
| `normalize_for_equivalence(left, right)` | 把两个 DFA 补到并集字母表，供乘积搜索使用 |

## 3. 输入规范（统一约定）

### 3.1 状态、字母表与转移

- 状态名与符号一律用字符串；状态顺序、字母表顺序按录入顺序保留，方便
  打印和与题图逐行对照。
- DFA 的转移必须是全函数。题图数据、B/C 的自构用例都应写成完整表；这样
  第一、二题不会出现“这题把缺边当拒绝、那题把缺边当错误”的冲突。
- 状态名只要求在一个自动机内部唯一；两个自动机可以重名（例如都用 `A`），
  乘积 DFA 用状态对区分，不存在命名冲突。

### 3.2 部分转移表：统一补陷阱

只有确实要表达“缺边即拒绝”时才用 `Automaton.from_partial`：

```python
dfa = Automaton.from_partial(
    states=["P", "Q"],
    alphabet=["0", "1"],
    start_state="P",
    accepting_states={"Q"},
    transitions={"P": {"0": "P", "1": "Q"}},   # Q 的行缺失
)
```

规则：

1. 缺失的行/缺失的符号统一指向陷阱状态（默认名 `__trap__`，必要时追加
   `__trap___1` 之类的新名字）。
2. 陷阱状态只在对它有转移时加入 `states`；它自己对所有符号自环。
3. 陷阱状态不是终态，因此缺边等价于拒绝。
4. 如果 `trap_state` 与已有状态同名，就把该状态当作陷阱使用，不再新增。
5. 转移指向一个既不是现有状态、也不是 `trap_state` 的名字，仍然报错，防止
   拼写错误被悄悄补成陷阱。

### 3.3 字母表不同：不能直接判不等价

两个 DFA 的字母表可以不同。判断语言关系前必须统一到并集：

```python
from automaton import normalize_for_equivalence

a1, a2 = normalize_for_equivalence(a1, a2)
# 此后两个自动机的 alphabet 相同，可以逐符号做乘积搜索
```

反例：`{ε}` 在 `{0}` 上是 `{ε}`，在 `{0,1}` 上仍是 `{ε}`；空语言在 `{0}`
和 `{1}` 上都是 `∅`。B 现在的 `question1.py` 第 81–82 行用
`a1.alphabet != a2.alphabet` 直接返回“字母表不同”，会把这些情况误判为
不等价。A 只提供 `normalize_for_equivalence` 这个接口，**不代改 B 的文件**；
B 在收尾时把等价函数改成先调用它即可。

`complete_to` 只增加字母表、不改变原有字母表上的语言；新符号一律进入
陷阱并被拒绝，所以并集补齐不会引入本不属于原语言的串。

### 3.4 不可达状态

公共类允许不可达状态，因为题图录入和“自构含不可达状态”的测试都需要它。
第二题的 `minimize_dfa` 先删除不可达状态，因此它返回的映射只包含可达的
原状态；不可达状态不会出现在映射里。这是第二题固定的接口约定。

`{FS2, FS5, FS6}`；字母表 `{0,1}`。题面特别注明 `IS0` 在 `0` 和 `1` 上

| 状态 | 0 | 1 |
