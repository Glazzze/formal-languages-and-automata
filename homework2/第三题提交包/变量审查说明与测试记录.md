## 一、题目要求与判定目标

判定语言 `L = {0^k 1^k | k ≥ 1}`，读入字符串后输出“接受”或“拒绝”。题面同时规定：

1. 必须显式维护堆栈 `S`，不能用递归；
2. 除堆栈 `S`、输入字符串 `s` 和遍历循环变量外，不显式定义其他存储变量；
3. 空串必须拒绝，`0011`、`011`、`0101` 等示例要给出正确结论。

`question3.py` 只包含判定核心 `judge(s)` 和按题面示例打印结论的主程序；测试数据与统计变量全部放在独立的 `verify.py` 中，两份文件互不混入。

## 二、判定算法

栈 `S` 同时承担两种信息：

- 每个 `"0"` 表示一个尚未匹配的前导 `0`；
- 阶段标记 `"|"` 始终位于所有未匹配 `"0"` 之上，表示“已经开始读 `1`”。

| 读入情况 | 栈操作 | 结果 |
| --- | --- | --- |
| 读 `0`，栈顶不是 `"\|"`（含空栈） | 压入 `"0"` | 继续 |
| 读 `0`，栈顶是 `"\|"` | 无 | 拒绝：`1` 之后又出现 `0` |
| 读 `1`，栈为空 | 无 | 拒绝：前面没有 `0` |
| 读 `1`，栈顶是 `"0"` | 弹出该 `"0"`，压入 `"\|"` | 进入/保持 `1` 阶段 |
| 读 `1`，栈顶是 `"\|"` | 弹出 `"\|"`，再弹出栈顶 `"0"`，压回 `"\|"`；下面已无 `"0"` 则拒绝 | 匹配一个 `1` |
| 其它字符 | 无 | 拒绝 |
| 输入结束 | 检查 `S == ["\|"]` | 成立接受，否则拒绝 |

由此得到三条边界结论：

- **空串**：循环不执行，`S == []`，不满足 `S == ["|"]`，拒绝，符合 `k ≥ 1`；
- **先读 `1` 后又读 `0`**：`"|"` 在匹配每个 `1` 后都会被压回栈顶，之后遇到 `0` 时第 7 行的 `S[-1] == "|"` 判定成立直接拒绝，不会被误接收；
- **`0` 与 `1` 数量不等**：`1` 偏多时由第 15 行的空栈检查拒绝，`0` 偏多时输入结束后栈中仍残留 `"0"`，`S == ["|"]` 不成立。

因为每读一个 `1` 恰好消耗栈中一个 `"0"`，所以“还剩多少个未匹配的 `0`”直接由栈内 `"0"` 的个数表示，不需要计数器。

## 三、变量审查说明

### 3.1 允许使用的变量清单

| 名称 | 类别 | 作用 | 是否题面允许 |
| --- | --- | --- | --- |
| `s` | 函数参数 | 待判定字符串 | 允许（输入字符串） |
| `S` | 局部变量 | 显式堆栈，唯一的存储结构 | 允许（显式堆栈） |
| `ch` | `for` 循环变量 | 当前读入的字符 | 允许（遍历循环变量） |

### 3.2 未使用的变量与结构

判定函数中不存在：计数器、下标变量、阶段布尔标志、结果变量、额外列表/集合/字典、字符串缓冲、全局变量、`global`/`nonlocal` 声明、递归调用与辅助函数。函数无副作用，只返回 `True`/`False`；返回值是表达式结果，不是存储变量。阶段信息存放在栈标记 `"|"` 中，已匹配个数由栈内 `"0"` 的个数表示。

### 3.3 逐行审查

| 行号 | 语句 | 使用的变量 | 说明 |
| --- | --- | --- | --- |
| 1 | `def judge(s: str) -> bool:` | `s` | 唯一参数 |
| 3 | `S = []` | `S` | 唯一的容器，显式堆栈 |
| 5 | `for ch in s:` | `s`、`ch` | 唯一的循环，唯一的循环变量 |
| 6–9 | `if ch == "0":` … `S.append("0")` | `ch`、`S` | `0` 阶段压栈 |
| 7–8 | `if S and S[-1] == "\|": return False` | `S` | 拒绝 `1` 之后的 `0` |
| 10–12 | `elif ch == "1":` … `if not S: return False` | `ch`、`S` | 拒绝没有 `0` 对应的 `1` |
| 13–18 | 栈顶为 `"\|"`：弹标记、弹 `0`、压回标记 | `S` | 匹配一个 `1` |
| 15–16 | `if not S or S[-1] != "0": return False` | `S` | 拒绝多余（无 `0` 可配）的 `1` |
| 19–23 | 栈顶为 `"0"`：弹出一个 `"0"` 后压入 `"\|"` | `S` | 由 `0` 阶段进入 `1` 阶段 |
| 24–25 | `else: return False` | `ch` | 拒绝 `0`/`1` 以外的字符 |
| 27 | `return S == ["\|"]` | `S` | 结束条件：栈中恰剩下阶段标记 |

主程序的 `print` 语句只是按题面输出结论，不属于判定核心，也没有引入新的存储变量。

## 五、跨题独立验证

`verify.py` 的后半部分是本题负责人承担的跨题核验：题图数据独立录入，算法独立实现，因此不依赖组内 `question1.py`、`question2.py` 也能给出预期结果；组内代码存在时再与实际对象对照。

### 5.1 独立录入的题图数据

自动机 1：

| → A | A | B |

自动机 2（图中只有 `C` 是双圈终态，接受空串）：

| 状态 | 0 | 1 |

| 状态 | 0 | 1 |
| --- | --- | --- |

两份数据在 `verify.py` 中分别写成 `Q1_MACHINE_1`、`Q1_MACHINE_2`、`Q2_MACHINE_D`，格式与题面一致：`{"Q", "SIGMA", "DELTA", "q0", "F"}`，并由 `check_dfa` 检查状态引用、确定性与完整性。

### 5.2 独立实现的方法

| 检查 | 方法 |
| --- | --- |
| 数据合法性 | `check_dfa`：初态/终态/转移指向合法，每个“状态 × 符号”都有唯一转移 |
| 一般等价判定 | 乘积自动机上的广度优先搜索，终态判据为“恰好一个分量为终态”，返回最短区分串 |
| 可达性 | 从初态广度优先遍历，与状态集合比较 |
| 最小性 | 全部状态可达，且任意两个不同状态都能找到区分串 |
| 短串核对 | 按长度、字典序枚举，比较两台自动机的接受结果 |
| 合并关系 | 把原 DFA 的每个状态轮流当作起点，与最小化 DFA 的各个状态比较语言，要求唯一对应 |
| 核验器自检 | 另构造一对等价自动机（2 状态与 3 状态），确认检查函数不会误判 |

### 5.3 独立结论

| 检查 | 结果 |
| --- | --- |
| 第一题题图两个自动机 | 不等价，最短区分串 `ε`（自动机 1 不接受空串，自动机 2 接受） |
| 第一题短串核对 | 63 个串，首次差异为 `ε`，与一般判定一致 |
| 核验器自检 | 一对等价自动机判定等价，63 个串全部一致 |
| 第二题自动机 D 的语言 | 长度模 3 余 2 的 0/1 串，长度 0～8 共 511 个串一致 |
| 第二题可达性 | 7 个状态全部可达 |
| 第二题最小性 | 独立预期自动机 3 个状态，全部可达且两两可区分 |
| 第二题合并关系 | `X ← {IS0, S3}`、`Y ← {S1, S4}`、`Z ← {FS2, FS5, FS6}` |

### 5.4 与组内实际代码的集成核验

把 `question3.py`、`verify.py` 与组内 `question1.py`、`C/question2.py` 放在同一目录后运行，`verify.py` 会自动加载两者的实际对象（`as_dfa_dict` 统一为字典格式）并复核：

```text
== 跨题集成核验：组内实际代码 ==
  第一题反例：B 与独立判定一致（不等价，区分串 ε）
  第一题正例：B 与独立判定一致（等价）
  第二题：C 的最小化结果 3 个状态，可达且两两可区分，与原 DFA 等价，511 个短串一致
  第二题合并关系一致：[['FS2', 'FS5', 'FS6'], ['IS0', 'S3'], ['S1', 'S4']]
```

缺少其中任一文件时该段自动跳过并明确提示，不影响第三题部分的测试：

```text
== 跨题集成核验：组内实际代码 ==
  跳过：未找到 question1.py, C\question2.py
集成核验：未执行（当前目录缺少 question1.py 或 C/question2.py）；第二题最小状态数 3。
```

C 的最小化状态命名为 `Q0/Q1/Q2`，与本文档的 `X/Y/Z` 只是命名差异；核验比较的是状态分组（集合的集合）而不是名字。短串核对只用于查错，不替代乘积自动机与状态对算法的通用性结论。
