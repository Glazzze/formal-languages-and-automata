# 成员 C：DFA 最小化

## 文件

- `automaton.py`：第一、二题可复用的 DFA 类，检查状态、字母表和完整转移表。
- `question2.py`：通用状态对标记最小化算法、作业题 DFA D、自构测试 DFA、标记过程和运行入口。
- `test_question2.py`：独立单元测试。
- `运行结果.txt`：运行 `question2.py` 保存的完整控制台输出，包含题图 DFA 和自构 DFA 的标记、合并及结果。

在本目录运行：

```text
python question2.py
python -m unittest -v
```

## 算法

1. 从初态搜索并先删除不可达状态。
2. 第 0 轮标记接受状态与非接受状态组成的状态对。
3. 逐轮检查未标记对 `(p, q)`：若存在输入符号 `a`，使 `(δ(p,a), δ(q,a))` 已被标记，则标记 `(p,q)`。
4. 直到没有新标记。剩余未标记的状态对不可区分，将不可区分状态合并；每个合并组用一个代表状态生成完整转移。

## 接口与集成

- `question2.py` 只需要公共类提供 `Automaton`（字段与 `delta`、`accepts`、`reachable_states`、`pretty_print` 接口）。状态对的规范化辅助函数 `pair_key` 已放在 `question2.py` 内部，不要求 A 维护的 `automaton.py` 额外提供，避免公共类版本不一致导致导入失败。
- 最终提交包中公共自动机类只保留一份 `automaton.py`；本目录的 `question2.py` 可直接复用该文件，不需要再复制一份。
- `minimize_dfa` 返回的映射只包含可达的原状态；不可达状态在选择阶段已被删除，因此不会出现在映射中。这是本模块固定的接口约定。
- 计划中建议把自构用例集中到 `examples.py`。为保持本目录可独立运行，两个自构 DFA 暂时保留在 `question2.py` 的构造函数中，`question2.py` 不依赖 `examples.py`；合并提交时可按组长安排迁移。

## 作业题 DFA D

题图的状态为 `IS0、S1、FS2、S3、S4、FS5、FS6`，初态为 `IS0`，终态为 `{FS2, FS5, FS6}`，字母表为 `{0,1}`。特别按题目注释录入 `IS0` 在 `0` 和 `1` 上均转移至 `S1`。

| 状态 | 0 | 1 |
|---|---|---|
| IS0 | S1 | S1 |
| S1 | FS2 | FS5 |
| FS2 | IS0 | IS0 |
| S3 | S4 | S4 |
| S4 | FS5 | FS6 |
| FS5 | S3 | S3 |
| FS6 | IS0 | IS0 |

### 标记与合并结果

- 第 0 轮（终态/非终态不同）：`(FS2, IS0)`、`(FS2, S1)`、`(FS2, S3)`、`(FS2, S4)`、`(FS5, IS0)`、`(FS5, S1)`、`(FS5, S3)`、`(FS5, S4)`、`(FS6, IS0)`、`(FS6, S1)`、`(FS6, S3)`、`(FS6, S4)`。
- 第 1 轮（其后继对已标记）：`(IS0, S1)`、`(IS0, S4)`、`(S1, S3)`、`(S3, S4)`。
- 未标记等价类：`{FS2, FS5, FS6}`、`{IS0, S3}`、`{S1, S4}`。
- 所有题图状态均可从初态到达；无不可达状态需要删除。

程序输出的映射（新状态名由类中字典序确定）：

| 原状态 | 新状态 |
|---|---|
| FS2 | Q0 |
| FS5 | Q0 |
| FS6 | Q0 |
| IS0 | Q1 |
| S3 | Q1 |
| S1 | Q2 |
| S4 | Q2 |

最小 DFA：

- 状态集：`{Q0, Q1, Q2}`
- 字母表：`{0,1}`
- 初态：`Q1`
- 终态集：`{Q0}`

| 状态 | 0 | 1 |
|---|---|---|
| Q0 | Q1 | Q1 |
| Q1 | Q2 | Q2 |
| Q2 | Q0 | Q0 |

**最小性说明：** 三个商状态均从初态 `Q1` 可达：`Q1` 起始可达、读一个符号到 `Q2`、再读一个符号到 `Q0`。`Q0` 是接受状态，与两个非接受状态可由空串区分；`Q1` 和 `Q2` 读一个符号后分别到非接受 `Q2` 和接受 `Q0`，因此也可区分。所有状态两两可区分，结果已最小。

程序对输入 DFA 和最小 DFA 的所有长度不超过 5 的串作了接受性比对。这是辅助查错；语言等价性和最小性由状态对算法及上述区分依据保证，而不是由有限枚举代替。

## 自构 DFA 测试

`build_custom_merge_dfa()` 构造状态 `{A,B,C,X}` 的 DFA：`B`、`C` 都是接受状态且对所有输入留在自身，因此等价并合并；`X` 从初态不可达，会被删除。结果为 `{Q0={A}, Q1={B,C}}`，转移为 `Q0 --0,1--> Q1`、`Q1 --0,1--> Q1`。

`build_custom_minimal_dfa()` 构造识别“字符串中 `1` 的个数为偶数”的两状态 DFA。`E`、`O` 分别接受偶数和奇数个 `1`；两状态由空串可区分，故输入和结果都保持两状态。

两个自构例均通过程序内的长度 0 至 5 短串一致性检查；独立单元测试还检查预期映射、不可达状态剔除和最小状态数。
