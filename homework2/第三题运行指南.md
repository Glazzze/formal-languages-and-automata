## 运行环境

Python 3（在 3.12.7 上实测），只使用标准库，无需安装依赖、无需命令行参数。

## 运行命令

在 `homework2/提交版` 中执行以下命令。

```bash
python question3_stack_membership.py
python verify_submission.py
```

Windows 中文控制台如需固定 UTF-8 输出，可写成 `python -X utf8 verify_submission.py`。退出码 `0` 表示全部检查通过；任一项失败会抛出 `AssertionError` 并以非 0 退出。

## 说明

- 题面的变量限制只针对 `question3_stack_membership.py` 的判定核心 `judge`；`verify_submission.py` 是独立测试脚本，其中的用例与统计变量不进入判定程序，两者分文件存放。
- `verify_submission.py` 里的第一、二题数据按作业 PDF 与课件图独立录入，等价判定、可达性与最小性检查均在本文件独立实现，用于复核组内实现的结果。
- `verify_submission.py` 另对外提供 `check_question1_short_strings`、`check_question2_short_strings`、`check_minimality` 三个可复用检查函数，供组长联调时调用。
