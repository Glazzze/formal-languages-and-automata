## 具体分工

### 组员 1：第一题——语言的串接

- 自行构造两个语言 `L1` 和 `L2`，保证每个语言至少包含 3 个字符串。
- 编写以 `L1`、`L2` 为参数的语言串接函数。
- 使用 `print` 打印函数返回语言中的所有字符串。
- 提供一组可复现的测试数据和运行结果。
- 检查空字符串、重复结果以及集合去重问题，并在说明中写明处理方式。
- 交叉复核组员 3 的正例、负例和 DFA 输出格式。

### 组员 2：第二题——上界为 T 的星操作

- 自行构造至少包含 2 个字符串的语言 `L`。
- 编写以 `L`、`T` 为参数的有界星操作函数。
- 按题目要求测试 `T = 3`，并使用 `print` 打印返回语言中的所有字符串。
- 说明字符串拼接长度不超过 `T` 个语言元素的实现方式。
- 提供测试数据、运行结果和必要的边界情况说明。
- 交叉复核组员 4 录入的 NFA 转移表是否与题目一致。

### 组员 3：第三题——DFA 的转移函数与扩展转移函数

- 根据 `lec1-dfa` 中的 DFA 转移表实现 `delta(q, a)`。
- 实现通过调用 `delta(q, a)` 完成计算的扩展转移函数 `Edelta(q, s)`。
- 构造一个长度不少于 3 且被 DFA 接受的正例字符串 `Sp`。
- 构造一个长度不少于 3 且被 DFA 拒绝的负例字符串 `Sn`。
- 使用 `print` 输出 DFA 处理两个输入串时的每一次状态转移和最终状态。
- 检查正例、负例与终态集合是否一致。
- 交叉复核组员 1 和组员 2 的语言结果是否满足题目中的数量要求。

### 组员 4：第四题——NFA 子集构造核心算法

- 根据题目给出的 NFA 转移表录入状态、输入字符和转移集合。
- 实现 subset construction 的状态集合发现和转移计算部分，将 NFA 状态集合转换为 DFA 状态。
- 向组员 5 提供稳定的状态集合表示方式和转移计算接口。
- 提供核心算法测试结果，便于组员 5 完成最终输出。

### 组员 5：组长——第四题输出验证、整合与最终复核

- 在组员 4 的核心算法基础上完成 DFA 转移表打印、初态和终态标记。
- 独立运行第四题代码，核对生成的 DFA 转移表是否稳定、完整。
- 检查包含 NFA 终态 `9` 的状态集合是否被正确识别为 DFA 终态。
- 收集组员 1 至组员 4 的 Python 文件、测试数据和运行结果。
- 统一文件命名、函数命名、注释风格和输出格式，避免代码合并冲突。
- 将各题代码整理为最终提交目录，并编写 `README.md` 说明运行方法和成员分工。
- 运行全部代码，检查语法错误、编码问题和题目要求是否全部满足。
- 负责压缩包命名、邮件标题核对以及纸质版打印材料的整理。

## 统一协作要求

1. 每位成员提交自己的 Python 源文件、测试输入和运行截图或文本结果。
2. 各题代码应尽量使用独立文件，建议命名为 `question1.py`、`question2.py`、`question3.py` 和 `question4.py`。
3. 所有输出应清楚体现题目要求的语言结果、状态转移或 DFA 转移表。
4. 组员 5 整合前，每位成员先自行运行代码并修复语法错误。
5. 最终提交前，五位成员都应阅读并运行完整代码，确保能够解释自己负责的题目以及整体运行结果。
