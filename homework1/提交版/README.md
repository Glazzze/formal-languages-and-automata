## 各题输入与预期结果

### 第一题：语言的串接

文件：`question1.py`；函数：`concatenate_language(L1, L2)`。

自行构造的语言为：

```python
L1 = {"a", "AB", "cde", "FGHI"}
L2 = {"10", "211", "3222", "43333"}
```

将每个 `L1` 元素与每个 `L2` 元素依次串接，返回去重后的集合，并打印全部 16 个结果。集合的打印顺序可能随运行变化，不影响结果。

| L1 元素 | 对应的串接结果 |
| --- | --- |
| `a` | `a10`、`a211`、`a3222`、`a43333` |
| `AB` | `AB10`、`AB211`、`AB3222`、`AB43333` |
| `cde` | `cde10`、`cde211`、`cde3222`、`cde43333` |
| `FGHI` | `FGHI10`、`FGHI211`、`FGHI3222`、`FGHI43333` |

### 第二题：语言的有界星操作

文件：`question2.py`；函数：`bounded_star(L, T)`。

自行构造的语言和参数为：

```python
L = {"q", "qu", "u"}
T = 3
```

使用深度优先搜索生成拼接 0～3 个语言元素的字符串，并通过集合去重。预期输出 **33 个不同字符串**，含空串；空串打印为 `ε`，结果按字符长度和字典序排列。

`T` 限制的是拼接的语言元素个数，例如 `quququ` 由三个 `qu` 拼接得到，符合要求。不同拼接方式可能生成相同字符串，例如 `qu` 与 `q + u`，最终只保留一次。

本次使用的参数为非负整数 `T = 3`；函数未对非法参数进行校验。

### 第三题：DFA 的转移函数与扩展转移函数

文件：`question3.py`；主要函数：`delta(q, a)`、`Edelta(q, s)`。

DFA 初态为 `A`，终态集合为 `{A, B}`，接受所有不含连续两个 `1` 的二进制字符串。`Edelta` 通过调用 `delta` 实现，并打印每次转移。

| 用例 | 输入串 | 状态路径 | 最终结果 |
| --- | --- | --- | --- |
| 正例 | `101` | `A → B → A → B` | `accepted` |
| 负例 | `111` | `A → B → C → C` | `rejected` |

### 第四题：NFA 的子集构造

文件：`question4.py`；主要函数：`subset_construction(nfa, alphabet, start, final)`、`print_dfa(...)`。

使用题目指定的 NFA，初态为 `1`，终态集合为 `{9}`，字母表为 `{r, b}`，没有空串转移。以 `frozenset` 表示状态子集，通过队列发现全部可达 DFA 状态，打印转移表、初态和终态。

预期生成 **7 个可达状态**，初态为 `D0`，终态为 `D5、D6`。`->` 表示初态，`*` 表示终态。

| 标记 | DFA 状态 | NFA 状态子集 | r | b |
| --- | --- | --- | --- | --- |
| -> | D0 | {1} | D1 | D2 |
| | D1 | {2,4} | D3 | D4 |
| | D2 | {5} | D3 | D5 |
| | D3 | {2,4,6,8} | D3 | D6 |
| | D4 | {1,3,5,7} | D3 | D6 |
| * | D5 | {1,3,7,9} | D3 | D2 |
| * | D6 | {1,3,5,7,9} | D3 | D6 |
