# 第四题：NFA 的子集构造

运行 `python question4.py` 即可打印 DFA 转移表。程序只使用 Python 标准库。

## 算法

题目中 NFA 的初态是 1，终态集合是 {9}，字母表是 {r, b}，没有 ε 转移。

1. 将初态子集 {1} 作为 DFA 初态，并放入待处理队列。
2. 每次取出一个子集 S，对每个字符 a，将 S 中所有 NFA 状态在 a 下的目标状态取并集，得到 DFA 的目标子集。
3. 如果目标子集尚未出现，就记录它并加入队列，直到队列为空。
4. 包含 NFA 终态 9 的子集就是 DFA 终态。

核心公式：δ_D(S, a) = ⋃（q ∈ S）δ_N(q, a)。

例如，δ_D({2,4}, r) = {4,6} ∪ {2,8} = {2,4,6,8}。

## 得到的 DFA 转移表

`->` 表示初态，`*` 表示终态。D0～D6 是程序按发现顺序分配的名称。

| 标记 | DFA 状态 | 对应的 NFA 状态子集 | r | b |
| --- | --- | --- | --- | --- |
| -> | D0 | {1} | D1 | D2 |
| | D1 | {2,4} | D3 | D4 |
| | D2 | {5} | D3 | D5 |
| | D3 | {2,4,6,8} | D3 | D6 |
| | D4 | {1,3,5,7} | D3 | D6 |
| * | D5 | {1,3,7,9} | D3 | D2 |
| * | D6 | {1,3,5,7,9} | D3 | D6 |

因此，转换得到的 DFA 有 **7 个可达状态**，初态为 **D0**，终态集合为 **{D5, D6}**。这里保留子集构造得到的状态，没有额外进行 DFA 最小化。

## 验证

已检查全部 DFA 转移是否符合并集公式，并枚举长度为 0～12 的全部 8191 个输入串，逐一比较原 NFA 与转换后 DFA 的接受结果，全部一致。

示例：空串、`r`、`b`、`rr`、`rb` 被拒绝；`bb`、`rrb`、`rbb` 被接受。
