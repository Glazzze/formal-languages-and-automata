# 形式语言与自动机：第一次 Python 编程作业实验指导书

## 实验说明

本次作业围绕语言运算、确定有限自动机（DFA）模拟以及非确定有限自动机（NFA）的子集构造算法展开。除特别说明外，要求使用 Python 编程，并使用 `print` 语句输出规定结果。

## 第一题（5 分）：语言的串接

假设 `L₁` 是一个语言（即一组字符串构成的集合），`L₂` 是另一个语言。两个语言的串接定义为：

\[
L_1L_2=\{xy\mid x\text{ 是 }L_1\text{ 中的一个字符串，且 }y\text{ 是 }L_2\text{ 中的一个字符串}\}。
\]

编写一个以两个语言 `L₁` 与 `L₂` 为输入参数的串接函数，完成 `L₁` 与 `L₂` 的串接。

要求：

- 自行构造 `L₁` 与 `L₂`，使得每个语言中的字符串个数大于或等于 3；
- 使用 `print` 语句打印串接函数调用执行的结果，即打印函数返回的语言中的所有字符串。

## 第二题（5 分）：语言的有界星操作

假设 `L` 是一个语言（即一组字符串构成的集合），定义 `L` 上界为 `T` 的星操作为：

\[
S^T(L)=\{w_1w_2\cdots w_n\mid n\leq T，\text{且每个 }w_i\in L\}。
\]

编写一个以 `L` 与 `T` 为参数的上界为 `T` 的星操作函数。

要求：

- 自行构造 `L`，使得 `L` 中的字符串个数大于或等于 2；
- 使用 `print` 语句打印该函数在 `T = 3` 时调用执行的结果，即打印函数返回的语言中的所有字符串。

## 第三题（10 分）：DFA 的转移函数与扩展转移函数

考虑课件 `lec1-dfa` 中的 DFA。该 DFA 接受所有不含两个连续 `1` 的 `0/1` 字符串，例如 `"0"`、`"01"`、`"1"`、`"101"`。

### DFA 结构

- 状态集：`Q = {A, B, C}`
- 输入字母表：`Σ = {0, 1}`
- 初态：`q₀ = A`
- 终态集：`F = {A, B}`

转移函数如下：

| 当前状态 | 输入 `0` | 输入 `1` |
| --- | --- | --- |
| `A` | `A` | `B` |
| `B` | `A` | `C` |
| `C` | `C` | `C` |

可参考以下 Python 数据结构描述：

```python
dfa = {
    'Q': {'A', 'B', 'C'},
    'SIGMA': {'0', '1'},
    'DELTA': {
        ('A', '0'): 'A',
        ('A', '1'): 'B',
        ('B', '0'): 'A',
        ('B', '1'): 'C',
        ('C', '0'): 'C',
        ('C', '1'): 'C',
    },
    'q0': 'A',
    'F': {'A', 'B'},
}
```

### 编程要求

1. 编写以状态 `q` 与字符 `a` 为参数的转移函数 `delta(q, a)`。
2. 编写以状态 `q` 与字符串 `s` 为参数的扩展转移函数 `Edelta(q, s)`。
3. `Edelta(q, s)` 必须通过调用 `delta(q, a)` 实现。
4. 自行构造一个被上述 DFA 接受的正例字符串 `Sₚ`，以及一个被上述 DFA 拒绝的负例字符串 `Sₙ`；`Sₚ` 与 `Sₙ` 各自包含的字符个数都要大于或等于 3。
5. 通过调用 `Edelta(q, s)`，实现上述 DFA 分别以 `Sₚ` 与 `Sₙ` 作为输入串的执行过程。
6. 使用 `print` 语句打印上述 DFA 的每一次转移。

## 第四题（10 分）：NFA 的子集构造算法

考虑课件 `lec2-nfa` 中由下表定义的 NFA。表中 `r` 与 `b` 是输入字符；每个单元格中的数字表示在相应输入字符下可以到达的状态集合。

箭头 `→` 表示初态，星号 `*` 表示终态。

| 状态 | `r` | `b` |
| --- | --- | --- |
| → 1 | 2, 4 | 5 |
| 2 | 4, 6 | 1, 3, 5 |
| 3 | 2, 6 | 5 |
| 4 | 2, 8 | 1, 5, 7 |
| 5 | 2, 4, 6, 8 | 1, 3, 7, 9 |
| 6 | 2, 8 | 3, 5, 9 |
| 7 | 4, 8 | 5 |
| 8 | 4, 6 | 5, 7, 9 |
| * 9 | 6, 8 | 5 |

编写 Python 程序，完成课件 `lec2-nfa` 中的 **subset construction**（子集构造）算法。

要求使用 `print` 语句打印上述 NFA 通过执行 subset construction 算法得到的 DFA 转移表。
